# Prompt 04 — Implement Baseline

现在根据 docs/algorithm-spec.md 实现 Baseline。

只实现密码学算法，不做 GUI，不处理图片/视频。

要求：

1. Setup / KeyGen / Encrypt / Decrypt 分离；
2. 数据结构清晰；
3. 使用安全随机源；
4. 不使用硬编码密钥；
5. 不用 mock 替代密码学核心；
6. 为每个核心函数编写测试；
7. 测试至少包括：
   - 单用户授权
   - 多用户授权
   - 不同授权集合
   - 非授权用户
   - 多次随机加密
   - 密文不能直接还原明文
   - 解密结果完整一致
8. 解密失败必须被正确处理；
9. 如果存在工程简化，明确标记；
10. 不要为了通过测试而改变算法语义。

完成后：
- 运行全部相关测试；
- 输出测试结果；
- 更新 README；
- 不要做 GUI。

如果发现算法规格存在问题，先停止并报告，不要自行猜测。
