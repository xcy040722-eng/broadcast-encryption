# Broadcast Encryption Course Project — Agent Starter

这是“基于广播加密的图像/视频安全共享系统”课程设计的 Agent 启动包。

## 使用方式

1. 将本目录中的 `CLAUDE.md` 复制到 VSCode 项目根目录。
2. 将 `prompts/` 复制到项目中。
3. 按编号依次执行 Prompt，不要跳过 Research / Specification 阶段。
4. Agent 每完成一个阶段后，先人工检查产出，再进入下一阶段。
5. 密码学核心实现必须能够追溯到论文中的算法或公式。

## 推荐阶段

M0 项目初始化
M1 经典广播加密 Baseline
M2 图片/视频混合加密
M3 可视化
M4 Matrix Commitment 学习与规格化
M5 WW25 可行性评估与实现
M6 WW25 + 文件 + GUI
M7 CHW25（仅在前面稳定后进行）

## 核心原则

先理解 → 再规格化 → 再实现 → 再测试 → 再审计 → 最后可视化。
