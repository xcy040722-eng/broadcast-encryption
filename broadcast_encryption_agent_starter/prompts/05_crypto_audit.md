# Prompt 05 — Cryptographic Audit

你现在不是开发者，而是密码学代码审计员。

【不要修改代码】。

审查当前 Baseline 实现。

检查：

1. 是否忠实实现论文算法？
2. Setup 是否正确？
3. KeyGen 是否正确？
4. Encrypt 是否正确？
5. Decrypt 是否正确？
6. 授权用户为什么可以解密？
7. 非授权用户为什么不能解密？
8. 是否存在绕过授权集合的方法？
9. 是否把“程序报错”错误地当成“密码学安全”？
10. 是否使用安全随机数？
11. 是否存在 nonce/IV 复用？
12. 是否存在硬编码密钥？
13. 是否把 toy construction 冒充正式方案？
14. 数学公式与代码是否一致？
15. 边界条件是否存在漏洞？
16. 测试是否真的覆盖核心性质？

输出按：

CRITICAL
HIGH
MEDIUM
LOW

分类。

每个问题给出：
- 文件
- 函数
- 问题
- 为什么有问题
- 建议

最后给出：
PASS / CONDITIONAL PASS / FAIL
